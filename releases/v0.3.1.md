# v0.3.1

> Released: 2026-03-15

## Breaking Changes

*   **Database Schema Updates:** Significant changes to the database schema including the addition of new tables (`activity_log`, `projects`, `workspace_runtime_services`) and modifications to existing tables (`goals`, `projects`). These updates are reflected in new migration files and schema definitions, impacting the underlying data structure.
*   **Automated Goal & Issue Management Enhancements:** Introduced new agent wakeups and context endpoints for goals and issues. This redefines how agents interact with and manage goals and issues, potentially impacting agent logic relying on previous states or payloads. Key changes include:
    *   New `heartbeat-context` endpoints for goals (`/goals/:id/heartbeat-context`) and issues (`/issues/:id/heartbeat-context`) providing richer context for agents.
    *   New automated agent wakeups triggered by approval status changes (rejection/revision), goal activation, subgoal completion, and issue completion.
    *   New `/goals/:id/pursue` endpoint and `link-project`/`unlink-project` functionalities for goals.

## Highlights

*   **Automated Goal Management:** Goals are now reactive with automated pursuit, approval gating, and completion detection, streamlining goal execution and tracking.
*   **Enhanced Agent Workflow:** New `heartbeat-context` endpoints for goals and issues provide agents with more comprehensive information to make informed decisions.
*   **New `openclaw` Command:** A new command-line interface command, `openclaw`, has been added for [describe purpose if known, otherwise omit].

## Improvements

*   **Efficient Agent Issue Fetching:** Introduced a new `/agents/me/inbox-lite` endpoint for efficiently retrieving a lightweight list of issues assigned to an agent.
*   **New Skill Integration:** The `para-memory-files` skill is now accessible via the API.
*   **Improved Session Context:** Added a `forceFreshSession` option for agent session context, allowing for more control over session re-initialization.
*   **Goal-Linked Issues:** Enhanced the issues endpoint by adding a `goalId` filter, enabling easier retrieval of issues associated with specific goals.
*   **Paginated Comments:** The `listComments` endpoint has been improved with `afterCommentId`, `order`, and `limit` query parameters for better pagination control.
*   **Goal Project Linking:** Added `link-project` and `unlink-project` endpoints for managing project associations with goals.
*   **Performance Optimization:** Optimized heartbeat token usage to improve efficiency.
*   **UI/UX Enhancements:** Includes a new `worktree:cleanup` command and improvements to the new issue dialog, such as skipping pre-filled fields when tabbing.

## Fixes

*   Fixed the issue service's goal completion detection logic.
*   Addressed review findings related to pursue status guard, cross-company project validation, agent assignments rendering, and wakeup error handling.
*   **CLI:** Environment variables with special characters are now correctly quoted.
*   **Database Setup:** Embedded PostgreSQL databases now ensure UTF-8 encoding. Constructor types for embedded PostgreSQL now align with `initdbFlags` usage.
*   **Worktree Management:** Addressed various internal fixes for worktree, codex, token optimization, heartbeat, and process error handling.
*   **Routing Fixes:** Resolved issues with manual company switch route synchronization and remembered company switch routes.
