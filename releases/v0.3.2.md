# v0.3.2

> Released: 2026-03-15

## Highlights

- Goals are now first-class citizens, enabling automated pursuit, approval gating, and completion detection.
- Introduced `worktree:cleanup` command and improved environment variable handling for worktrees.

## Improvements

- Added 'Me' and 'Unassigned' options for issue/task assignees.
- Improved issue dialog UX by skipping pre-filled assignee/project fields when tabbing.
- Delayed the creation of onboarding starter tasks until the user explicitly launches them.
- Optimized heartbeat token usage for better resource management.
- Enhanced worktree UI with branding.
- Updated the sidebar Documentation link to point to the external `docs.paperclip.ing`.

## Fixes

- Addressed various issues including: pursue status guard, cross-company project validation, agent assignment rendering, wakeup error handling, `greptile` follow-up, and token optimization edge cases.
- Resolved CLI issues with quoting environment variables and fixing local skill installation for moved `.agents` skills.
- Fixed worktree-related bugs such as seed source selection, codex home isolation, and UI branding inconsistencies.
- Improved application routing by fixing company switch route synchronization.
- Corrected type errors in the `process-lost-reaper` process.
- Prevented false `process_lost` failures in the heartbeat mechanism for specific run states.
- Reverted a previous PR related to pre-merge lockfile refresh.
- Ensured embedded PostgreSQL databases correctly use UTF-8 encoding.
- Fixed runtime skills to be scoped correctly to `./skills` and preferred `.agents` skills.

## Breaking Changes

- None detected.

## Upgrade Guide

- No explicit breaking changes were introduced in this release, so no specific upgrade steps are required beyond standard updates.
