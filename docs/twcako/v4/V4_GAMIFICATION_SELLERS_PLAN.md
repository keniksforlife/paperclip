# TWCako Gamification System
## Seller/Affiliate Retention Program

**Created:** 2026-02-15
**Target Users:** Sellers (TAP Affiliates)
**Goal:** Increase seller retention and daily engagement

---

## 1. Overview

### Problem
Sellers (TAP Affiliates) become inactive after initial sign-up. We need to keep them engaged daily.

### Solution
A gamification system that rewards sellers for daily activities with XP (experience points), badges, streaks, and ranks.

### Target Audience

| User Type | Included? | Notes |
|-----------|-----------|-------|
| TAP Affiliates | ✅ Yes | Primary target |
| VIP Customers | ✅ Yes | Can participate |
| Global Distributors | ❌ No | Already have TWC Rewards |
| Loyal Customers | ❌ No | Not sellers |

### Difference from TWC Rewards

| TWC Rewards (Existing) | Gamification (New) |
|------------------------|-------------------|
| For Distributors | For Sellers/Affiliates |
| Big milestones (10+ distributors) | Daily small actions |
| eCash bonuses (₱2K-10K) | XP points, badges, ranks |
| Recruitment focused | Engagement focused |
| Monthly/quarterly goals | Daily/weekly goals |

## 2. XP (Experience Points) System

### 2.1 What is XP?

XP (Experience Points) are earned through daily activities. XP accumulates to:
- Unlock badges
- Increase rank/level
- Qualify for rewards
- Climb leaderboards

### 2.2 XP Earning Activities

#### Daily Engagement

| Activity | XP | Frequency | Notes |
|----------|-------|-----------|-------|
| Daily login | +5 XP | Once per day | Must log into dashboard |
| Complete profile | +20 XP | One-time | Photo, bio, contact info |
| Watch training video | +5 XP | Per video | Any course video |
| Complete a lesson | +10 XP | Per lesson | Full lesson completion |

#### Sales Activities

| Activity | XP | Frequency | Notes |
|----------|-------|-----------|-------|
| Make a sale | +10 XP | Per sale | Any completed sale |
| Sale above ₱500 | +15 XP | Per sale | Bonus for bigger sales |
| Sale above ₱1,000 | +25 XP | Per sale | Replaces +10 base |
| Sale above ₱5,000 | +50 XP | Per sale | Replaces +10 base |
| First sale of the day | +5 XP | Once per day | Bonus on first sale |
| 3 sales in one day | +20 XP | Once per day | Daily achievement |
| 5 sales in one day | +50 XP | Once per day | Daily achievement |

#### Funnel & Prospect Activities

| Activity | XP | Frequency | Notes |
|----------|-------|-----------|-------|
| Share funnel link | +2 XP | Per share | Social media share |
| Prospect visits funnel | +1 XP | Per visitor | Unique visitors |
| Prospect opts in | +5 XP | Per opt-in | Email/phone captured |
| Prospect watches video | +3 XP | Per prospect | >50% watch time |
| Prospect checks out | +10 XP | Per checkout | Initiates checkout |
| Prospect purchases | +25 XP | Per purchase | Completed purchase |

#### Training & Bootcamp

| Activity | XP | Frequency | Notes |
|----------|-------|-----------|-------|
| Attend ABC Day 1 | +50 XP | One-time | Live or replay |
| Attend ABC Day 2 | +50 XP | One-time | Live or replay |
| Attend ABC Day 3 | +100 XP | One-time | Most important day |
| Complete ABC | +100 XP | One-time | Bonus for completing all |
| ABC Certificate | +50 XP | One-time | Certificate awarded |
| Attend DBC | +200 XP | One-time | Distributor bootcamp |

#### Referral Activities

| Activity | XP | Frequency | Notes |
|----------|-------|-----------|-------|
| Refer a new seller | +50 XP | Per referral | New affiliate signs up |
| Referral makes first sale | +25 XP | Per referral | Bonus |
| Referral completes ABC | +25 XP | Per referral | Bonus |

## 3. Streak System

### 3.1 What are Streaks?

Streaks reward consistency. Do an activity multiple days in a row to build a streak and earn bonus XP.

### 3.2 Streak Types

#### Login Streak

| Streak | Bonus XP | Badge Unlocked |
|--------|----------|----------------|
| 3 days | +10 XP | - |
| 7 days | +25 XP | "Week Warrior" |
| 14 days | +50 XP | - |
| 30 days | +100 XP | "Monthly Master" |
| 60 days | +200 XP | - |
| 90 days | +500 XP | "Consistency King" |
| 180 days | +1,000 XP | "Half Year Hero" |
| 365 days | +2,500 XP | "Legendary" |

#### Sales Streak

| Streak | Bonus XP | Badge Unlocked |
|--------|----------|----------------|
| 3 days | +25 XP | - |
| 7 days | +75 XP | "Sales Machine" |
| 14 days | +150 XP | - |
| 30 days | +500 XP | "Unstoppable Seller" |

#### Visitor Streak (Daily funnel visitors)

| Streak | Bonus XP | Badge Unlocked |
|--------|----------|----------------|
| 7 days | +50 XP | "Traffic Driver" |
| 30 days | +200 XP | "Marketing Pro" |

### 3.3 Streak Rules

- Miss one day = streak resets to 0
- Streak counter visible on dashboard
- Push notification reminder before streak breaks
- "Streak Freeze" power-up (future feature - preserves streak for 1 day)

## 5. Rank System

### 5.1 Rank Progression

Ranks are based on **lifetime XP earned**. Higher ranks unlock perks and recognition.

| Level | Rank Name | XP Required | Total XP | Perks |
|-------|-----------|-------------|----------|-------|
| 1 | Starter | 0 | 0 | Basic access |
| 2 | Bronze | 250 | 250 | Profile badge |
| 3 | Silver | 500 | 750 | Leaderboard eligible |
| 4 | Gold | 1,000 | 1,750 | XP multiplier 1.1x |
| 5 | Platinum | 2,000 | 3,750 | XP multiplier 1.15x |
| 6 | Diamond | 3,500 | 7,250 | XP multiplier 1.2x |
| 7 | Elite | 5,000 | 12,250 | XP multiplier 1.25x |
| 8 | Legend | 10,000 | 22,250 | XP multiplier 1.5x, Special badge |

### 5.2 Rank Benefits

| Benefit | Bronze | Silver | Gold | Platinum | Diamond | Elite | Legend |
|---------|--------|--------|------|----------|---------|-------|--------|
| Profile Badge | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

| XP Multiplier | 1x | 1x | 1.1x | 1.15x | 1.2x | 1.25x | 1.5x |

| Training watched | University signal | Award training XP |
| Funnel visitor | Prospect signal | Award visitor XP |
| Prospect opt-in | Prospect signal | Award opt-in XP |

### 10.3 Celery Tasks

| Task | Schedule | Purpose |
|------|----------|---------|
| `check_streaks` | Daily midnight | Reset broken streaks |
